# claude-statusline-astro

Claude Code 화면 맨 아래에 **지금 어디서 무엇을 하고 있는지**를 한 줄로 띄워 줍니다.

![상태라인 예시](docs/use.png)

지금 폴더, git 브랜치, 쓰는 모델, 사용량, 그리고 맨 뒤에 내 마스코트가 보입니다.
Windows · macOS · Linux 어디서나 같은 모양입니다.

> 개인 프로젝트입니다. Anthropic과는 관계가 없습니다.

---

# 1. 설치하기

## 가장 쉬운 방법

Claude Code를 켜고, 채팅창에 아래 세 줄을 **한 줄씩 차례로** 입력하세요.

```
/plugin marketplace add black-astro/claude-statusline-astro
```
```
/plugin install statusline@black-astro
```
```
/statusline-install
```

끝입니다. 세 번째 줄까지 꼭 실행해야 적용됩니다.

## 터미널을 쓰는 게 편하다면

> **터미널**은 명령어를 입력하는 창입니다. Windows는 PowerShell, macOS는 터미널 앱을
> 열면 됩니다.

**Windows (PowerShell)** — 아래 한 줄을 복사해서 붙여넣고 엔터

```powershell
irm https://raw.githubusercontent.com/black-astro/claude-statusline-astro/main/install.ps1 | iex
```

**macOS · Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/black-astro/claude-statusline-astro/main/install.sh | sh
```

## 설치하면 어디에 깔리나

전부 홈 폴더 안 `.claude` 폴더에 들어갑니다.

| 운영체제 | 설치 위치 |
| --- | --- |
| Windows | `C:\Users\사용자이름\.claude\` |
| macOS | `/Users/사용자이름/.claude/` |
| Linux | `/home/사용자이름/.claude/` |

문서에서 `~` 로 적힌 건 전부 이 홈 폴더를 뜻합니다. 즉 `~/.claude/statusline.sh` 는
Windows라면 `C:\Users\사용자이름\.claude\statusline.ps1` 입니다.

설치 프로그램이 하는 일은 이게 전부입니다.

1. `~/.claude/` 에 스크립트를 복사합니다
2. `~/.claude/settings.json` 에 필요한 설정을 더합니다 (**원래 있던 설정은 지우지 않습니다**)
3. 혹시 몰라 `settings.json.bak` 으로 백업해 둡니다

**설치 후 Claude Code를 완전히 닫았다가 다시 열어 주세요.** 그래야 줄이 나타납니다.

# 2. 처음 한 번: 마스코트 뽑기

설치 직후에는 마스코트가 **아직 없습니다.** 한 번 뽑아야 나타납니다.

Claude Code 채팅창에 이렇게 입력하세요.

```
/statusline-roll
```

이렇게 나옵니다.

```
오늘의 마스코트를 뽑았습니다!

  ･ﾟ✧（◕ᴗ◕）✧ﾟ･  [레전드 1/7종]
  표정 4장  ･ﾟ✧（◕ᴗ◕）✧ﾟ･ ･ﾟ✦（◕ᴗ◕）✦ﾟ･ ･ﾟ✧（◕ᴗ◕）✦ﾟ･ ･ﾟ✦（◕ᴗ◕）✧ﾟ･
  대사      요청하신 작업 모두 완료했습니다!

다음 뽑기는 내일부터 가능합니다.
```

이제 화면 맨 아래 줄 끝에 이 얼굴이 따라다닙니다.

# 3. 매일 쓰는 법

외울 건 두 개뿐입니다.

| 입력 | 하는 일 |
| --- | --- |
| `/statusline-roll` | 마스코트 뽑기 — **하루 한 번** |
| `/statusline-today` | 지금 내 마스코트 보기 |

터미널에서 쓰고 싶다면 이렇게 씁니다.

```sh
# macOS · Linux
~/.claude/mascot roll     # 뽑기
~/.claude/mascot          # 지금 마스코트
```

```powershell
# Windows
~\.claude\mascot.cmd roll
~\.claude\mascot.cmd
```

**뽑기는 하루에 한 번**입니다. 뽑지 않으면 지금 얼굴이 그대로 남습니다. 마음에 드는
얼굴이 나왔다면 며칠이든 그대로 두세요. 저절로 바뀌지 않습니다.

<details>
<summary>명령어가 더 있습니다 (안 외워도 됩니다)</summary>

| Claude Code 안에서 | 하는 일 |
| --- | --- |
| `/statusline-install` | 설치·재설치 |
| `/statusline-roll` | 마스코트 뽑기 |
| `/statusline-today` | 지금 마스코트 보기 |
| `/statusline-update` | 최신 버전으로 업데이트 |
| `/statusline-help` | 도움말 |

터미널에서는 스크립트를 직접 부를 수도 있습니다.

```sh
sh ~/.claude/statusline.sh --roll      # 뽑기
sh ~/.claude/statusline.sh --today     # 지금 마스코트
sh ~/.claude/statusline.sh --version   # 버전
sh ~/.claude/statusline.sh --help      # 도움말
```

</details>

# 4. 화면 읽는 법

```
DIR 내프로젝트 | GIT main | MODEL Opus 5 | CTX [◼◼◻◻◻◻◻◻◻◻] 21% | 5H [◼◼◼◻◻◻◻◻◻◻] 34% 1h49m （・ω・）
```

| 보이는 것 | 뜻 |
| --- | --- |
| `DIR` | 지금 작업 중인 **프로젝트 폴더 이름** |
| `GIT` | 지금 **git 브랜치**. `main`·`master` 는 보라색, 나머지는 하늘색 |
| `MODEL` | 지금 쓰는 **모델 이름** |
| `CTX` | **대화가 얼마나 찼는지.** 100%에 가까우면 앞쪽 대화가 밀려나기 시작합니다 |
| `5H` | **5시간 사용 한도.** 뒤의 `1h49m` 은 한도가 초기화되기까지 남은 시간 |
| 맨 뒤 얼굴 | **내 마스코트** |

게이지 색은 초록(60% 미만) → 주황(60% 이상) → 빨강(90% 이상) 순으로 바뀝니다.

`5H` 가 `--%` 로만 나온다면 Claude.ai 구독 플랜이 아닌 경우입니다. 사용량 정보가
내려오지 않아서이고, 나머지는 정상 동작합니다.

# 5. 안 될 때

**줄이 아예 안 보여요**
Claude Code를 완전히 닫았다 여세요. 그래도 없으면 `/statusline-install` 을 한 번 더
실행하세요.

**마스코트만 안 보여요**
아직 안 뽑아서입니다. `/statusline-roll` 을 입력하세요.

**글자가 네모(□)로 깨져요**
터미널 폰트가 그 글자를 못 그리는 경우입니다. D2Coding, Cascadia Code, JetBrains Mono
같은 폰트로 바꿔 보세요.

**색이 안 나와요**
`NO_COLOR` 환경변수가 켜져 있는지 확인하세요. 아주 오래된 터미널은 256색을 지원하지
않습니다.

**설치가 됐는지 확인하고 싶어요**

```sh
sh ~/.claude/statusline.sh --version
```

버전이 나오면 정상입니다.

# 마스코트

## 등급

등급이 오를수록 얼굴이 화려해집니다. 장식이 붙고, 팔이 생기고, 색이 흐릅니다.

표정은 **절반이 웃는 얼굴, 절반이 시크하거나 근엄하거나 화난 얼굴**입니다. 뽑을
때마다 분위기가 달라집니다.

| 등급 | 확률 | 색 | 종류 | 생김새 |
| --- | --- | --- | --- | --- |
| 커먼 | 40% | 흰색 | 12종 | 맨얼굴, 장식 없음 |
| 언커먼 | 35% | 초록 | 12종 | 밝은 표정, 장식 없음 |
| 레어 | 18% | 하늘색 | 12종 | 한쪽 장식이나 한 손 |
| 유니크 | 6% | 보라 | 10종 | 양쪽 장식 + 두 손 |
| 레전드 | 1% | 얼굴마다 다른 색이 흐름 | 7종 | 양쪽 겹장식 + 표정 4장 + 색이 흐름 |

얼굴은 전부 57종입니다. 레전드는 100일에 하루쯤 나옵니다.

## 말은 필요할 때만

작업 중이거나, 막 끝났거나, 무언가 확인을 기다릴 때만 한마디 합니다. 그 외에는
조용히 얼굴만 있습니다. 완료 대사는 1분이 지나면 사라집니다.

| 등급 | 작업 중 | 작업 끝 | 알림 |
| --- | --- | --- | --- |
| 커먼 | `끙...` | `냥!` | `앙?` |
| 언커먼 | `하는 중!` | `다했다!` | `저기요!` |
| 레어 | `작업 중이에요` | `끝났어요` | `확인해 주세요` |
| 유니크 | `처리하고 있어요!` | `다 끝냈습니다!` | `확인 부탁해요!` |
| 레전드 | `작업을 진행하고 있습니다!` | `전부 끝냈습니다, 확인 부탁드려요!` | `확인 부탁드립니다!` |

등급이 낮을수록 울음소리에 가깝고, 높을수록 문장이 또렷해집니다.

## 움직입니다

얼굴마다 표정이 여러 장 있고, Claude가 작업하는 동안 번갈아 나옵니다. 눈을 깜빡이는
정도라 요란하지 않습니다. 작업이 끝나면 첫 표정으로 멈춥니다.

**레전드는 글자마다 색이 다릅니다.** 한 글자씩 색을 입히고 그 띠가 계속 흘러갑니다.
표정도 4장이라 가만히 둬도 반짝입니다.

레전드는 **얼굴마다 색이 다릅니다.** 색상환을 한 바퀴 도는 대신 좁은 색 구간을

# 설정 바꾸기

고칠 거리는 전부 스크립트 맨 위에 모여 있습니다. `~/.claude/statusline.sh` 또는
`~/.claude/statusline.ps1` 을 열어 값만 바꾸면 됩니다.

| 바꾸고 싶은 것 | sh | PowerShell |
| --- | --- | --- |
| 막대 길이 | `BAR_LEN=10` | `$BarLength = 10` |
| 막대 문양 | `BAR_FULL='◼'` `BAR_EMPTY='◻'` | `$BarFull` `$BarEmpty` |
| 색 바뀌는 기준 | `WARN_AT=60` `CRIT_AT=90` | `$WarnAt` `$CritAt` |
| 프로젝트 이름 최대 길이 | `DIR_MAX=32` | `$DirMax = 32` |
| 주간(7일) 게이지 켜기 | `SHOW_SEVEN_DAY=1` | `$ShowSevenDay = $true` |
| 마스코트 끄기 | `SHOW_MASCOT=0` | `$ShowMascot = $false` |
| 마스코트 대사 끄기 | `SHOW_MASCOT_TALK=0` | `$ShowMascotTalk = $false` |
| 애니메이션 주기(초) | `ANIM_SECS=3` | `$AnimSecs = 3` |
| 완료 후 말하는 시간(초) | `TALK_WINDOW_SECS=60` | `$TalkWindowSecs = 60` |

색을 아예 빼려면 `NO_COLOR=1` 환경변수를 주면 됩니다.

등급 확률(`MASCOT_ODDS`)은 이 목록에 없습니다. 고정값이라 손대지 않는 쪽이 맞습니다.

막대 문양으로 자주 쓸 만한 조합: `▮`/`▯`, `▉`/`░`, `█`/`░`, `●`/`○`, 폰트가 빈약하면
`#`/`-` 도 괜찮습니다.

# 사용량 숫자에 대해

`CTX` 는 지금 이 순간 값이고, `5H` 는 조금 전 값일 수 있습니다. 창을 열어만 두고
오래 쓰지 않았다면 숫자가 잠깐 뒤처질 수 있는데, 다시 대화를 시작하면 맞춰집니다.

오래된 값일 때는 `~11%` 처럼 물결표가 붙습니다. 남은 시간 카운트다운은 언제나
정확합니다.
