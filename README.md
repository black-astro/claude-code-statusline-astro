# claude-statusline-astro

Claude Code 화면 맨 아래에 **지금 상태를 한 줄로** 보여 줍니다.

![상태라인 예시](docs/use.png)

작업 중인 폴더, git 브랜치, 쓰는 모델, 대화가 얼마나 찼는지, 5시간 한도가 얼마나 남았는지. 그리고 줄 끝에는 **내 마스코트**가 앉아 있습니다. 뽑기로 얻는 얼굴이고, 하루에 한 번만 뽑을 수 있습니다.

Windows, macOS, Linux 어디서 써도 같은 모양입니다.

> 개인이 만든 프로젝트입니다. Anthropic과는 관계가 없습니다.

## 1. 설치

### Claude Code 안에서 (가장 쉬움)

Claude Code를 열고, 채팅창에 아래 세 줄을 **한 줄씩** 입력합니다.

```
/plugin marketplace add black-astro/claude-statusline-astro
```
```
/plugin install statusline@black-astro
```
```
/statusline-install
```

세 번째 줄까지 끝나면 설치는 끝입니다.

### 터미널에서

터미널이 더 편하다면 한 줄이면 됩니다.

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/black-astro/claude-statusline-astro/main/install.ps1 | iex
```

macOS, Linux, WSL:

```sh
curl -fsSL https://raw.githubusercontent.com/black-astro/claude-statusline-astro/main/install.sh | sh
```

### 설치 후

**Claude Code를 완전히 닫았다가 다시 여세요.** 그래야 줄이 나타납니다.

설치 프로그램이 건드리는 곳은 홈 폴더의 `.claude` 폴더뿐입니다. 스크립트 몇 개를 복사하고, `settings.json`에 필요한 항목을 더합니다. 원래 있던 설정은 그대로 두고, 혹시 몰라 `settings.json.bak`으로 백업도 남깁니다.

| 운영체제 | 홈 폴더의 `.claude` |
| --- | --- |
| Windows | `C:\Users\사용자이름\.claude\` |
| macOS | `/Users/사용자이름/.claude/` |
| Linux | `/home/사용자이름/.claude/` |

이 문서에서 `~/.claude/`라고 적힌 곳은 모두 이 폴더입니다.

## 2. 마스코트 뽑기

설치 직후에는 마스코트가 **없습니다.** 한 번 뽑아야 나타납니다.

Claude Code 채팅창에 입력하세요.

```
/statusline-roll
```

이렇게 나옵니다.

```
오늘의 마스코트를 뽑았습니다!

  （◕‿◕）✧  Glow  [레어 3/12]
  표정 2장  （◕‿◕）✧ （◠‿◠）✦
  대사      다 됐어요 / 끝났어요 / 완료했어요 / 해냈어요! / 준비 끝!

다음 뽑기는 내일부터 가능합니다.
```

얼굴마다 영어 이름이 하나씩 붙어 있습니다. 위 예시라면 `Glow`입니다.

알아 둘 것은 세 가지입니다.

- **뽑기는 하루에 한 번**입니다. 오늘 뽑았다면 내일 다시 뽑을 수 있습니다.
- **안 뽑으면 그대로**입니다. 마음에 드는 얼굴이 나왔다면 며칠이든 두세요. 저절로 바뀌지 않습니다.
- **어디서 열어도 같은 얼굴**입니다. 다른 프로젝트, 다른 터미널, 새로 연 세션 모두 지금 뽑아 둔 얼굴이 따라옵니다.

<br>

## 3. 명령어

외울 건 두 개입니다.

| 입력 | 하는 일 |
| --- | --- |
| `/statusline-roll` | 마스코트 뽑기 (하루 한 번) |
| `/statusline-today` | 지금 내 마스코트와 이름 보기 |

나머지는 필요할 때만 씁니다.

| 입력 | 하는 일 |
| --- | --- |
| `/statusline-update` | 최신 버전으로 업데이트 |
| `/statusline-install` | 설치, 재설치 |
| `/statusline-help` | 짧은 도움말 |

터미널에서 바로 쓰고 싶다면 이렇게 합니다.

```sh
# macOS · Linux · WSL
~/.claude/mascot roll        # 뽑기
~/.claude/mascot             # 지금 마스코트
```

```powershell
# Windows
~\.claude\mascot.cmd roll    # 뽑기
~\.claude\mascot.cmd         # 지금 마스코트
```

## 4. 한 줄 읽는 법

```
DIR my-project | GIT main | MODEL Opus 5 | CTX [◼◼◻◻◻◻◻◻◻◻] 21% | 5H [◼◼◼◻◻◻◻◻◻◻] 34% 1h49m （◕‿◕）✧
```

| 항목 | 뜻 |
| --- | --- |
| `DIR` | 지금 작업 중인 **프로젝트 폴더** 이름 |
| `GIT` | 지금 **브랜치**. `main`과 `master`는 보라색, 나머지는 하늘색 |
| `MODEL` | 지금 쓰는 **모델** |
| `CTX` | **대화가 얼마나 찼는지.** 100%에 가까워지면 앞쪽 대화가 정리되기 시작합니다 |
| `5H` | **5시간 사용 한도.** 뒤의 `1h49m`은 한도가 새로 시작되기까지 남은 시간 |
| 맨 끝 | **내 마스코트** |

게이지는 60% 미만이면 초록, 60% 이상이면 주황, 90% 이상이면 빨강입니다.

`CTX`는 세션마다 따로 셉니다. 새 터미널은 0%에서 시작합니다. `5H`는 계정 전체가 함께 쓰는 값이라 어느 터미널에서나 같습니다. 잠깐 뒤처진 값이 보일 때는 앞에 `~`가 붙는데, 메시지를 하나 보내면 바로 맞춰집니다.

### 마스코트가 말할 때

평소에는 얼굴만 조용히 있습니다. 세 순간에만 한마디 합니다.

| 순간 | 예 |
| --- | --- |
| Claude가 작업하는 동안 | `작업 중이에요` |
| 작업이 막 끝났을 때 (1분 동안) | `끝났어요` |
| 확인을 기다릴 때 | `확인해 주세요` |

작업하는 동안에는 표정도 번갈아 바뀝니다. 눈을 깜빡이는 정도라 요란하지 않습니다.

## 5. 마스코트 도감

얼굴은 모두 **53종**, 다섯 등급입니다. 등급이 오를수록 장식이 붙고, 팔이 생기고, 레전드는 색이 흐릅니다. 어느 등급이든 **웃는 얼굴 반, 시크하거나 근엄한 얼굴 반**입니다.

| 등급 | 확률 | 색 | 얼굴 수 | 생김새 |
| --- | --- | --- | --- | --- |
| 커먼 | 40% | 흰색 | 12 | 맨얼굴 |
| 언커먼 | 35% | 초록 | 12 | 표정이 뚜렷한 맨얼굴 |
| 레어 | 18% | 하늘색 | 12 | 장식 하나, 또는 두 팔 |
| 유니크 | 6% | 보라 | 10 | 양쪽 장식과 두 팔 |
| 레전드 | 1% | 얼굴마다 다른 색이 흐름 | 7 | 겹장식, 표정 4장, 흐르는 색 |

확률은 고정값입니다. 누가 뽑든 같은 표로 뽑습니다.

## 6. 설정 바꾸기

바꿀 만한 값은 전부 스크립트 **맨 위**에 모여 있습니다. `~/.claude/statusline.sh` 또는 `~/.claude/statusline.ps1`을 열어 숫자만 고치면 됩니다. 저장하면 열려 있는 세션에도 몇 초 안에 반영됩니다. 재시작은 필요 없습니다.

| 바꾸고 싶은 것 | sh | PowerShell |
| --- | --- | --- |
| 마스코트 끄기 | `SHOW_MASCOT=0` | `$ShowMascot = $false` |
| 마스코트 대사 끄기 (얼굴만) | `SHOW_MASCOT_TALK=0` | `$ShowMascotTalk = $false` |
| 표정 바뀌는 간격 (초) | `ANIM_SECS=2` | `$AnimSecs = 2` |
| 레전드 색이 흐르는 속도 (초당 칸) | `GRADIENT_SPEED=1.5` | `$GradientSpeed = 1.5` |
| 레전드 색을 256색으로 (트루컬러가 안 되는 터미널) | `LEGEND_TRUE_COLOR=0` | `$LegendTrueColor = $false` |
| 완료 후 말하는 시간 (초) | `TALK_WINDOW_SECS=60` | `$TalkWindowSecs = 60` |
| 게이지 길이 | `BAR_LEN=10` | `$BarLength = 10` |
| 게이지 문양 | `BAR_FULL='◼'` `BAR_EMPTY='◻'` | `$BarFull` `$BarEmpty` |
| 색이 바뀌는 기준 (%) | `WARN_AT=60` `CRIT_AT=90` | `$WarnAt` `$CritAt` |
| 프로젝트 이름 최대 길이 | `DIR_MAX=32` | `$DirMax = 32` |
| 주간(7일) 게이지 켜기 | `SHOW_SEVEN_DAY=1` | `$ShowSevenDay = $true` |

색을 전부 빼고 싶으면 `NO_COLOR=1` 환경변수를 켜면 됩니다.

등급 확률은 고정값이라 설정에 없습니다.

<br>

## 7. 안 될 때

**줄이 아예 안 보입니다.**
Claude Code를 완전히 닫았다가 다시 여세요. 그래도 없으면 `/statusline-install`을 한 번 더 실행하세요.

**마스코트만 안 보입니다.**
아직 안 뽑은 경우입니다. `/statusline-roll`을 입력하세요. 뽑았는데도 없다면 아래 항목을 보세요.

**마스코트가 잘리거나 줄이 두 줄로 넘어갑니다.**
터미널이 좁아서 줄 끝이 밀려난 것입니다. 창을 넓히거나, 대사를 끄면(`SHOW_MASCOT_TALK=0`) 얼굴만 남아 짧아집니다. 프로젝트 이름이 길면 `DIR_MAX`를 줄여도 됩니다.

**글자가 네모(□)나 물음표로 나옵니다.**
터미널 폰트에 그 글자가 없는 경우입니다. D2Coding, Cascadia Code, JetBrains Mono처럼 기호가 넉넉한 폰트로 바꿔 보세요.

**`5H`가 `--%`로만 나옵니다.**
Claude.ai 구독 플랜이 아니면 사용량이 내려오지 않습니다. 나머지는 정상 동작합니다.

**색이 안 나옵니다.**
`NO_COLOR` 환경변수가 켜져 있는지 확인하세요. 아주 오래된 터미널은 256색을 지원하지 않습니다.

**레전드 색만 이상하게 나옵니다.**
레전드는 24비트 색을 씁니다. 터미널이 256색까지만 지원하면 `LEGEND_TRUE_COLOR=0` (PowerShell은 `$LegendTrueColor = $false`)으로 바꾸세요. 색이 가장 가까운 256색으로 맞춰집니다.

**레전드 색이 뚝뚝 끊겨 보입니다.**
줄은 `settings.json`의 `refreshInterval`(초)마다 다시 그려집니다. 설치 프로그램은 2로 맞춰 두는데, 예전에 설치했다면 3일 수 있습니다. 2로 낮추면 더 부드럽게 흐릅니다. 1은 그리기 비용이 커서 권하지 않습니다.

**설치가 됐는지 확인하고 싶습니다.**

```sh
sh ~/.claude/statusline.sh --version
```
```powershell
powershell -File ~\.claude\statusline.ps1 -Version
```

버전이 나오면 정상입니다.

<br>

## 8. 지우기

1. `~/.claude/settings.json`을 열어 `statusLine` 항목과, `hooks` 안에서 `mascot-hook`이 들어간 항목을 지웁니다.
2. `~/.claude/` 안의 `statusline.*`, `mascot*`, `statusline-cache` 폴더를 지웁니다.

플러그인으로 설치했다면 `/plugin uninstall statusline@black-astro`도 실행하세요.
