# claude-code-statusline-astro

Claude Code 화면 맨 아래에 **지금 어디서 무엇을 하고 있는지**를 한 줄로 띄워 줍니다.

![상태라인 예시](docs/use.png)

지금 폴더, git 브랜치, 쓰는 모델, 사용량, 그리고 맨 뒤에 내 마스코트가 보입니다.
Windows · macOS · Linux 어디서나 같은 모양입니다.

> 개인 프로젝트입니다. Anthropic과는 관계가 없습니다.

---

# 1. 설치하기

## 가장 쉬운 방법

Claude Code를 켜고, 채팅창에 아래 세 줄을 **한 줄씩 차례로** 입력하세요.

```
/plugin marketplace add black-astro/claude-code-statusline-astro
```
```
/plugin install statusline@black-astro
```
```
/statusline-install
```

끝입니다. 세 번째 줄까지 꼭 실행해야 적용됩니다.

## 터미널을 쓰는 게 편하다면

> **터미널**은 명령어를 입력하는 검은 창입니다. Windows는 PowerShell,
> macOS는 터미널 앱입니다.

**Windows (PowerShell)** — 아래 한 줄을 복사해서 붙여넣고 엔터

```powershell
irm https://raw.githubusercontent.com/black-astro/claude-code-statusline-astro/main/install.ps1 | iex
```

**macOS · Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/black-astro/claude-code-statusline-astro/main/install.sh | sh
```

## 설치하고 나면

**Claude Code를 완전히 닫았다가 다시 열어 주세요.** 그래야 화면 아래에 줄이 나타납니다.

설치 프로그램이 하는 일은 이게 전부입니다.

1. `~/.claude/` 폴더에 스크립트를 복사합니다
2. `~/.claude/settings.json` 에 필요한 설정을 더합니다 (**원래 있던 설정은 지우지 않습니다**)
3. 혹시 몰라 `settings.json.bak` 으로 백업해 둡니다

> `~` 는 내 홈 폴더를 뜻합니다. Windows면 `C:\Users\사용자이름`,
> macOS면 `/Users/사용자이름` 입니다.

# 2. 처음 한 번: 마스코트 뽑기

설치 직후에는 마스코트가 **아직 없습니다.** 한 번 뽑아야 나타납니다.

Claude Code 채팅창에 이렇게 입력하세요.

```
/roll
```

이렇게 나옵니다.

```
오늘의 마스코트를 뽑았습니다!

  （✧ᴗ✧）  [레전드]
  표정 4장  （✧ᴗ✧） （✦ᴗ✦） （★ᴗ★） （☆ᴗ☆）
  대사      요청하신 작업 모두 완료했습니다!

다음 뽑기는 내일부터 가능합니다.
```

이제 화면 맨 아래 줄 끝에 이 얼굴이 따라다닙니다.

# 3. 매일 쓰는 법

외울 건 두 개뿐입니다.

| 입력 | 하는 일 |
| --- | --- |
| `/roll` | 마스코트 뽑기 — **하루 한 번** |
| `/mascot` | 지금 내 마스코트 보기 |

터미널에서 쓰고 싶다면 이렇게 씁니다.

```sh
~/.claude/mascot roll     # 뽑기
~/.claude/mascot          # 지금 마스코트
```

```powershell
~\.claude\mascot.cmd roll
~\.claude\mascot.cmd
```

**뽑기는 하루에 한 번**입니다. 뽑지 않으면 지금 얼굴이 그대로 남습니다. 마음에 드는
얼굴이 나왔다면 며칠이든 그대로 두세요. 저절로 바뀌지 않습니다.

<details>
<summary>명령어가 더 있습니다 (안 외워도 됩니다)</summary>

| Claude Code 안에서 | 하는 일 |
| --- | --- |
| `/statusline-install` | 설치·재설치 |
| `/statusline-update` | 최신 버전으로 업데이트 |
| `/statusline-help` | 도움말 |

`/roll` 은 `/statusline-roll`, `/mascot` 은 `/statusline-today` 와 같습니다.

터미널에서는 `--roll`, `--today`, `--version`, `--help` 를 직접 쓸 수도 있습니다.

```sh
sh ~/.claude/statusline.sh --help
```

</details>

# 4. 화면 읽는 법

```
DIR 내프로젝트 | GIT main | MODEL Opus 5 | CTX [◼◼◻◻◻◻◻◻◻◻] 21% | 5H [◼◼◼◻◻◻◻◻◻◻] 34% 1h49m （・ω・）
```

| 보이는 것 | 뜻 |
| --- | --- |
| `DIR` | 지금 작업 중인 **프로젝트 폴더 이름** |
| `GIT` | 지금 **git 브랜치**. `main`·`master` 는 보라색, 나머지는 하늘색 |
| `MODEL` | 지금 쓰는 **모델 이름** |
| `CTX` | **대화가 얼마나 찼는지.** 100%에 가까우면 앞쪽 대화가 밀려나기 시작합니다 |
| `5H` | **5시간 사용 한도.** 뒤의 `1h49m` 은 한도가 초기화되기까지 남은 시간 |
| 맨 뒤 얼굴 | **내 마스코트** |

게이지 색은 초록(60% 미만) → 주황(60% 이상) → 빨강(90% 이상) 순으로 바뀝니다.

`5H` 가 `--%` 로만 나온다면 Claude.ai 구독 플랜이 아닌 경우입니다. 사용량 정보가
내려오지 않아서이고, 나머지는 정상 동작합니다.

# 5. 안 될 때

**줄이 아예 안 보여요**
Claude Code를 완전히 닫았다 여세요. 그래도 없으면 `/statusline-install` 을 한 번 더
실행하세요.

**마스코트만 안 보여요**
아직 안 뽑아서입니다. `/roll` 을 입력하세요.

**글자가 네모(□)로 깨져요**
터미널 폰트가 그 글자를 못 그리는 경우입니다. D2Coding, Cascadia Code, JetBrains Mono
같은 폰트로 바꿔 보세요.

**색이 안 나와요**
`NO_COLOR` 환경변수가 켜져 있는지 확인하세요. 아주 오래된 터미널은 256색을 지원하지
않습니다.

**직접 확인해 보고 싶어요**

```sh
sh ~/.claude/statusline.sh --version
```

버전이 나오면 설치는 정상입니다.

## 등급

| 등급 | 확률 | 색 | 얼굴 수 |
| --- | --- | --- | --- |
| 커먼 | 40% | 흰색 | 12 |
| 언커먼 | 35% | 초록 | 12 |
| 레어 | 18% | 하늘색 | 12 |
| 유니크 | 6% | 보라 | 9 |

| DEV | 10% *(등록된 키만)* | 시안 | 4 |

얼굴은 전부 54개입니다. 레전드는 100일에 하루쯤 나옵니다.

확률은 **고정값**입니다. 누가 쓰든 같은 표로 뽑습니다.

`DEV` 는 메인테이너 전용이라 다른 사람 키로는 나오지 않습니다.

## 말은 필요할 때만

작업 중이거나, 막 끝났거나, 무언가 확인을 기다릴 때만 한마디 합니다. 그 외에는
조용히 얼굴만 있습니다. 완료 대사는 1분이 지나면 사라집니다.

| 등급 | 작업 중 | 작업 끝 | 알림 |
| --- | --- | --- | --- |
| 커먼 | `끙...` | `왕!` | `앙?` |
| 언커먼 | `하는 중!` | `다했다!` | `저기요!` |
| 레어 | `작업 중이에요` | `해냈어요!` | `확인해 주세요` |
| 유니크 | `처리하고 있어요!` | `작업 완료했어요!` | `확인 부탁해요!` |
| 레전드 | `작업을 진행하고 있습니다!` | `요청하신 작업 모두 완료했습니다!` | `확인 부탁드립니다!` |
| DEV | `빌드 도는 중.` | `커밋하시죠.` | `입력 대기 중.` |

등급이 낮을수록 울음소리에 가깝고, 높을수록 문장이 또렷해집니다.

## 움직입니다

얼굴마다 표정이 여러 장 있고, Claude가 작업하는 동안 번갈아 나옵니다. 눈을 깜빡이는
정도라 요란하지 않습니다. 작업이 끝나면 첫 표정으로 멈춥니다.

**레전드는 글자마다 색이 다릅니다.** 한 글자씩 무지개 색을 입히고 그 띠가 3초마다 한
칸씩 흘러갑니다. 가만히 둬도 반짝입니다.

## 뽑기는 하루 한 번

날짜가 바뀌면 뽑을 권리가 다시 생기고, 뽑지 않으면 지금 얼굴이 그대로입니다.

뽑은 결과는 이 컴퓨터의 비밀키로 서명해서 보관합니다. 보관 파일을 손으로 고치면
서명이 맞지 않아 무시되므로, 등급을 원하는 값으로 바꿔 넣을 수는 없습니다. 뽑기도
암호학적 난수를 쓰기 때문에 결과를 미리 알거나 고를 수 없습니다.

비밀키는 설치 후 첫 대화가 끝날 때 한 번 만들어집니다
(`~/.claude/statusline-cache/.gacha-key`). 이 파일을 지우면 뽑은 마스코트도 함께
사라지니 그대로 두세요.

# 설정 바꾸기

고칠 거리는 전부 스크립트 맨 위에 모여 있습니다. `~/.claude/statusline.sh` 또는
`~/.claude/statusline.ps1` 을 열어 값만 바꾸면 됩니다.

| 바꾸고 싶은 것 | sh | PowerShell |
| --- | --- | --- |
| 막대 길이 | `BAR_LEN=10` | `$BarLength = 10` |
| 막대 문양 | `BAR_FULL='◼'` `BAR_EMPTY='◻'` | `$BarFull` `$BarEmpty` |
| 색 바뀌는 기준 | `WARN_AT=60` `CRIT_AT=90` | `$WarnAt` `$CritAt` |
| 프로젝트 이름 최대 길이 | `DIR_MAX=32` | `$DirMax = 32` |
| 주간(7일) 게이지 켜기 | `SHOW_SEVEN_DAY=1` | `$ShowSevenDay = $true` |
| 마스코트 끄기 | `SHOW_MASCOT=0` | `$ShowMascot = $false` |
| 마스코트 대사 끄기 | `SHOW_MASCOT_TALK=0` | `$ShowMascotTalk = $false` |
| 애니메이션 주기(초) | `ANIM_SECS=3` | `$AnimSecs = 3` |
| 완료 후 말하는 시간(초) | `TALK_WINDOW_SECS=60` | `$TalkWindowSecs = 60` |

색을 아예 빼려면 `NO_COLOR=1` 환경변수를 주면 됩니다.

등급 확률(`MASCOT_ODDS`)은 이 목록에 없습니다. 고정값이라 손대지 않는 쪽이 맞습니다.

막대 문양으로 자주 쓸 만한 조합: `▮`/`▯`, `▉`/`░`, `█`/`░`, `●`/`○`, 폰트가 빈약하면

# 사용량 숫자는 실시간인가

**CTX는 실시간이고, 5H와 7D는 시차가 있습니다.**

Claude Code가 넘겨주는 사용량 값은 **그 창이 마지막으로 응답을 받은 시점에 멈춰
있습니다.** 그래서 가만히 열어만 둔 터미널은 옛날 숫자를 들고 있습니다.

그래서 이 스크립트는 창마다 자기가 받은 값을 `~/.claude/statusline-cache/` 에 적어
두고, 그릴 때는 **모든 창이 적어 둔 값 중 가장 최신 것**을 씁니다. 덕분에 여러 창을
띄워 놔도 전부 같은 숫자를 보여줍니다.

이미 끝난 창의 값이면 `~11%` 처럼 물결표를 붙이고 흐리게 칠합니다. 남은 시간
카운트다운은 내 컴퓨터 시계로 계산하므로 언제나 정확합니다.

# 어떻게 동작하나

Claude Code는 상태라인 스크립트에 세션 정보를 JSON으로 넘기고, 스크립트가 출력한
**한 줄**을 그대로 화면에 띄웁니다.

```
Claude Code ──JSON──> statusline.ps1 / .sh ──한 줄──> 화면
```

마스코트는 조금 다릅니다. Claude Code는 "지금 작업 중인지"를 상태라인에 알려주지
않기 때문에, 훅 네 개가 그 상태를 파일에 적어 두고 상태라인이 읽어 갑니다.

| 훅 | 언제 | 적는 값 |
| --- | --- | --- |
| `UserPromptSubmit` | 질문을 보낼 때 | `working` |
| `Stop` | 답이 끝났을 때 | `done` |
| `StopFailure` | 실패했을 때 | `error` |
| `Notification` | 확인을 기다릴 때 | `notify` |

훅을 설치하지 않으면 이 파일이 생기지 않고, 마스코트도 나오지 않습니다. 상태라인은
마스코트가 없던 때와 똑같이 그려집니다.

쓰는 파일은 전부 `~/.claude/statusline-cache/` 안에 있고, 이틀 넘게 손대지 않은 것은
자동으로 지웁니다.

| 환경 | 쓰는 파일 | 필요한 것 |
| --- | --- | --- |
| Windows (PowerShell, cmd) | `scripts/statusline.ps1` | Windows PowerShell 5.1 (기본 설치됨) |
| macOS · Linux · WSL · Git Bash | `scripts/statusline.sh` | POSIX `sh` (`jq`는 있으면 쓰고 없어도 됨) |
